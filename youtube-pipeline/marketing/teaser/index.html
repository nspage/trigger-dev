Building a Local LLM Knowledge Base

Extracting high-signal data from unstructured YouTube transcripts.

Core Concepts

  • Data Source: YouTube transcripts via PubSubHubbub.
  • Processing: Gemini LLM for synthesis.
  • Orchestration: Trigger.dev running locally in Docker.

Outcome

A persistent, interlinked Markdown vault that compounds over time, preventing context loss and enabling powerful search.
