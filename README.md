# Trigger.dev Projects Workspace

This repository is a container for multiple Trigger.dev based projects and related resources.

## Directory Structure

- **`youtube-pipeline/`**: Local YouTube Transcript Pipeline for AI Knowledge Engineering. A local-first tool for extracting high-signal knowledge from YouTube videos using Trigger.dev and Google Gemini. Includes a Chrome extension, Cloudflare Worker, and local Docker worker.
- **`hyperframes-projects/`**: Hyperframes-related projects, tabs, and introductory content (`categories-tab`, `channels-tab`, `pending-tab`, `extension_demo`, `intro`, etc.).
- **`.agents/` & `.agent/`**: Global agent skills and workflows (e.g., Trigger.dev best practices, tasks, config).
- **`GEMINI.md`**: Global Trigger.dev v4 best practices and instructions inherited by all sub-projects.

## Sub-Projects

Please refer to the `README.md` inside each sub-project directory (e.g., `youtube-pipeline/README.md`) for specific setup and operational instructions.
