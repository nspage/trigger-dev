# YT LLM Pipeline Assistant Intro

30-second introduction to the YouTube Knowledge Pipeline Chrome Extension.

## Style Block
- **Palette**:
  - Background: `#0e0f11` (Deep Space)
  - Card/Panel: `#18191d` (Gunmetal)
  - Accent: `#5e6ad2` (Electric Indigo)
  - Text Main: `#ededed` (Ice White)
  - Text Muted: `#8b8f98` (Stone Grey)
  - Success: `#4ade80` (Mint)
  - Alert: `#f87171` (Coral)
- **Typography**:
  - Headline: `Geist` (Bold, 900)
  - Body: `Inter` (Medium, 500)
  - Data/Metadata: `JetBrains Mono` (Regular, 400)
- **Mood**: Snappy, professional, technical. Dark mode premium.

## Rhythm Declaration
`slow-build-BUILD-PEAK-breathe-CTA`

## Global Rules
- **Atmosphere**: Radial glows in `#5e6ad2` at 15% opacity. Monospace coordinate labels in corners.
- **Transitions**: Primary: CSS Vertical Push (0.4s, `power3.inOut`). Accent: Shader Cinematic Zoom (0.6s) for the hero reveal.
- **Ambient Motion**: All background decoratives have a "drift" motion (y: +/- 20px, 4s cycle).

## Per-Scene Beats

### Scene 1: The Extraction (0-5s)
- **Concept**: The infinite stream of YouTube content being distilled.
- **Mood**: High energy, technical.
- **Depth Layers**: 
  - BG: Deep navy fill + 3 rotating geometric wireframes in `#5e6ad2`.
  - MG: Large floating text "KNOWLEDGE EXTRACTION".
  - FG: Small code snippets (YouTube IDs) drifting vertically.
- **Choreography**: 
  - Text SLAMS in from scale 2.0 to 1.0.
  - Wireframes PULSE with a 2s cycle.
  - Code snippets DRIFT upwards at varying speeds.
- **Transition out**: CSS Vertical Push (up).

### Scene 2: The Noise (5-10s)
- **Concept**: Visual representation of "content overload" and the frustration of IP blocks.
- **Mood**: Glitchy, chaotic.
- **Depth Layers**:
  - BG: Grid of 16 grey boxes (thumbnails).
  - MG: Red "IP BLOCK" warning labels.
  - FG: "SKIP THE NOISE" headline.
- **Choreography**:
  - Grid boxes CASCADE in from center.
  - "IP BLOCK" labels FLASH in with a glitch effect.
  - Headline PUNCHES in from bottom.
- **Transition out**: CSS Vertical Push (up).

### Scene 3: The Architecture (10-20s)
- **Concept**: The clean, local-first solution using Trigger.dev and Gemini.
- **Mood**: Enlightened, structural.
- **Depth Layers**:
  - BG: Horizontal hairline rules in `#8b8f98` at 10% opacity.
  - MG: 4 nodes (CF Worker -> Extension -> Docker -> Gemini) connected by lines.
  - FG: "PROCESS LOCALLY" label.
- **Choreography**:
  - Nodes DROP in sequence (0.2s stagger).
  - Connecting lines DRAW from start to finish.
  - Central node (Extension) GLOWS as it receives signal.
- **Transition out**: Shader Cinematic Zoom (into Extension node).

### Scene 4: The Dashboard (20-25s)
- **Concept**: The Chrome Extension interface as the control center.
- **Mood**: Empowering, clean.
- **Depth Layers**:
  - BG: Blurred YouTube UI in background.
  - MG: The "YT LLM Pipeline Assistant" popup card.
  - FG: Floating "APPROVE" and "TRACK" icons.
- **Choreography**:
  - Popup card SLIDES in from right.
  - Status items in the list CASCADE from top to bottom.
  - "APPROVE" button PULSES with Success color.
- **Transition out**: CSS Blur Crossfade (0.6s).

### Scene 5: Ownership (25-30s)
- **Concept**: Final brand statement.
- **Mood**: Authoritative, calm.
- **Depth Layers**:
  - BG: Single large radial glow in `#5e6ad2`.
  - MG: Logo + "YT LLM Pipeline Assistant".
  - FG: "OWN YOUR KNOWLEDGE" subtitle.
- **Choreography**:
  - Logo TYPES ON.
  - Subtitle FADES IN with letter-spacing expansion (0 to 0.2em).
  - Background glow BREATHES slowly (scale 1.0 to 1.1).
- **Transition out**: Fade to black.

## Recurring Motifs
- Monospace labels for timestamps and coordinates.
- Horizontal/Vertical hairlines creating a "blueprint" feel.

## Negative Prompt
- No bright/warm colors except for small alerts.
- No rounded corners (keep it sharp and technical).
- No generic "cloud" icons (use architectural nodes).
